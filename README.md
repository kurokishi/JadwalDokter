# Sistem Jadwal Dokter RS

Aplikasi web berbasis Streamlit untuk menampilkan dan mengelola jadwal dokter
dalam format grid waktu (jam × dokter), siap untuk operasional Rumah Sakit.

## Fitur Utama
- Jadwal grid harian (mirip Excel RS)
- Mode TV / Fullscreen (read-only)
- Auto refresh
- Edit & validasi slot
- Export Excel (harian & mingguan)

## Cara Deploy (Streamlit Cloud)
1. Upload repository ini ke GitHub
2. Buka https://streamlit.io/cloud
3. Klik **New App**
4. Pilih repository
5. Main file: `app.py`
6. Klik Deploy

## File Data
- `jadwal hafis.xlsx` harus berada di root folder
